## 复现与检查

在项目根目录运行，Python 依赖为 `python-pptx`、`lxml`、`pymupdf` 和 `Pillow`，并安装 LibreOffice：

```bash
python 代码/figures/论文数据图/流程图工具/重绘流程图.py
python 代码/figures/论文数据图/流程图工具/导出核验.py --soffice libreoffice
```

导出程序检查所有流程图的 Office 数学对象、公式文字以及 PDF 页数，并刷新 PPT 文件缩略图，避免缩略图仍显示旧公式。旧版导出记录已移除，重新运行导出程序可生成当前记录。PNG 直接由对应 PPT 导出的 PDF 渲染，已检查主要版式的文字、分支及箭头走向。
