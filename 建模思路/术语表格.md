# 第一问术语表

|符号|中文 / English|单位|定义及禁止混用|
|---|---|---|---|
|t|时段索引 / interval index|无|0—143；按用户要求恢复附件时标为区间终点；不做循环移行|
|Δt|时间步长 / time step|h|1/6；功率须乘此值才能成为电量|
|p_t|电价 / electricity price|元/kWh|对应交付区间|
|L_t|负载功率 / load power|kW|不直接作为购电量|
|V_t|光伏预测功率 / forecast PV power|kW|第一问确定性输入，不称实际发电|
|g_t|计划购电量 / planned grid purchase|kWh|电网输入，无售电；不是kW|
|c_t|充电量 / charging energy|kWh|电网侧输入电池，内部增量0.9c_t|
|d_t|放电量 / discharging energy|kWh|电网侧输出，内部减量d_t/0.9|
|w_t|弃光电量 / curtailed PV energy|kWh|未利用光伏，0≤w_t≤V_tΔt|
|E_t|储电量 / stored energy|kWh|145个状态点；E_0=E_144，共同值由优化决定；不是百分比SOC|
|z_t|充电模式变量 / charging mode|无|二元变量；零充放电时无需解释模式|
|η_c,η_d|充放电效率 / charge and discharge efficiency|无|各0.9，往返0.81；待补充说明时可修订|
|MILP|混合整数线性规划 / mixed-integer linear programming|无|第一问既定求解路线|
|LP下界|线性松弛下界 / LP relaxation bound|元|用于检验目标最优性，不是额外执行策略|

所有符号首次定义于同目录《题目分析报告.md》，计算结果尚未冻结。

## 第二问补充

|符号|中文 / English|单位|定义及禁止混用|
|---|---|---|---|
|d|日期 / day index|无|2025全年索引；不要与第一问放电量d_t混用|
|q|放电量 / discharging energy|kWh|第二问使用q表示放电，与队友稿一致|
|e|紧急购电 / emergency purchase|kWh|费用为交付时段5p，不是储电E|
|w|总富余电量 / surplus spill|kWh|可能含剩余计划购电，不等于纯弃光|
|κ|终端单位储能价值 / terminal energy value|元/kWh|Φ(E)=−κE，只进入规划损失|
|C|实际交易费 / transaction cost|元|Σpg+5Σpe，不扣终端价值|
