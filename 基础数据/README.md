# 2026 年 C 题原始材料

本目录保存 2026 年高教社杯全国大学生数学建模竞赛 C 题“微网与外部电网电力调控策略”的官方题面与原始附件。

## 文件说明

- `C题.pdf`：赛题题面、四个问题、储能设备参数及附件说明。
- `附件1.xlsx`：单日分时电价、小区负载和光伏发电预测功率。
- `附件2.xlsx`：2025 年全年小区负载与光伏发电实际功率。
- `附件3.xlsx`：2025 年全年每日四个预报时刻发布的未来 24 小时光伏发电功率预测。
- `附件4.xlsx`：2025 年全年分时波动电价。

这些文件是未经处理的原始材料。清洗或衍生数据应另存到 `基础数据/processed` 或 `基础数据/features`，不要覆盖本目录文件。
