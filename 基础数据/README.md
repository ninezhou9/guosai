# 基础数据 (Data)

## 📌 目录定位
本目录用于统一存放竞赛期间的所有数据文件，包括原始附件、清洗后数据、特征衍生数据及中间结果。

## 📂 推荐子目录结构
- `raw/`：竞赛官方发布的原始数据附件（建议设为只读，保留原始备份）
- `processed/`：清洗、填补缺失值、异常值处理、标准化后的结构化数据
- `features/`：针对各题特征工程衍生出的特征集与指标矩阵
- `results/`：各模型求解产出的数值结果、预测值输出表格

## 📝 规范要求
1. 在本目录维护 `数据字典.md`，清晰记录各字段名称、业务含义、度量单位与数据类型。
2. 数据预处理过程必须有对应的代码脚本记录，保证数据流转可复现。
