# 论文写作 (Paper Writing)

## 📌 目录定位
本目录用于管理数学建模竞赛论文的撰写、排版、图表整合与最终提交文档。

## 📄 核心组成
1. **摘要 (Abstract)**：三段式高分结构（背景与核心目标 -> 各问模型方法与关键量化结论 -> 整体评价与创新点）。
2. **论文正文**：
   - 1. 问题重述与背景分析
   - 2. 模型假设与符号说明
   - 3. 问题一/二/三/四模型的建立与求解
   - 4. 灵敏度与稳定性分析
   - 5. 模型的评价、优缺点与推广
   - 6. 参考文献
   - 7. 附录（核心代码清单）
3. **排版工具支持**：
   - LaTeX 模板（推荐使用全国大学生数模竞赛官方/权威 ctexart 宏包模板）
   - Word 模板（标准国赛 2026 格式规范）

## 🔍 论文自检清单 (Checklist)
- [ ] 摘要是否包含明确的**量化数值结果**与结论？
- [ ] 符号表是否与正文公式完全对应一致？
- [ ] 图表是否有规范的图题、表题（三线表）、坐标轴物理单位与图例？
- [ ] 是否完成了灵敏度分析与误差分析？

## 当前题目结果材料

- `问题二/`：由代码真实运行生成的第二问结果报告，供正文引用前审核；完整数据表和复现文件仍保留在 `代码/实验/` 的对应目录。
- [ ] 承诺书及封面编号是否符合当年组委会官方规定？
