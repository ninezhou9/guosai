# 国赛数学建模项目 (guosai)

本项目为全国大学生数学建模竞赛（CUMCM）全流程实战与资料知识库，涵盖从赛题研读、数据清洗、模型构建、代码实现到论文写作的完整闭环。

---

## 🚀 模块说明与使用指引

### 1. [基础数据](./基础数据/)
- 存放赛题原始数据（附件 1、附件 2 等）及经过缺失值填补、归一化、特征工程后的数据文件。
- 建议在此目录下维护一份 `数据字典.md`，明确各字段含义、单位与缺失情况。

### 2. [建模思路](./建模思路/)
- 记录解题思维流、各问拆解（Question 1 ~ N）、模型假设合理性论证、符号说明表以及模型对比与创新点提炼。

### 3. [代码](./代码/)
- 存放本次比赛的全部可复现代码。
- 推荐统一管理依赖环境（如 `requirements.txt` 或 conda 环境说明），保证脚本整洁与模块化调用。

### 4. [论文写作](./论文写作/)
- 存放标准国赛论文初稿、终稿排版文件（支持 Word / LaTeX），包含关键的三段式摘要、结果分析与敏感性检验。

### 5. [资料](./资料/)
- **建模资料**：包含规划优化、灰色预测、时间序列、机器学习、综合评价等模型原理与讲义。
- **图表资料**：50+ 种高颜值图表制作方法、流程图/技术路线图中英文模板。
- **写作资料**：2001~2021 历年国奖优秀论文集、国家一等奖写作结构规范、论文格式模板。
- **代码资料**：14+ 种常用算法 Matlab/Python 源码、经典模型工具箱。

## 📌 竞赛规范与注意事项

1. **版本控制**：建议分问或分功能提交 commit，便于回溯与团队协同。
2. **论文规范**：摘要部分重点突出“问题-模型-算法-关键量化结论”四要素；支撑材料按组委会规范打包。
3. **可复现性**：确保代码运行结果与论文正文中的图表数据严格一致。
