# 支撑材料使用说明

本支撑材料只收录各问最终版本。当前五份答案位于 `结果/`，与原模板时间标签保持一致。四问原算法源码及新增跨日处理程序位于 `源码/代码/`；`结果/跨日补算/` 保存补算数值、假设和回填核验记录。

| 问题 | 主版本 |
| --- | --- |
| 第一问 | `源码/代码/q1_solution.py` |
| 第二问 | `源码/代码/实验/q2_fresh_20260912/` |
| 第三问 | `源码/代码/实验/q3_revision_a_20260912/` |
| 第四问 | `源码/代码/实验/q4_independent_codex_20260912/` |
| 跨日补算与模板回填 | `源码/代码/结果导出/` |

各问的核验程序、敏感性分析、模型选择记录和绘图工具用于支撑最终计算；`实验/` 下三个目录分别是第二、三、四问的最终实现。模型计算需使用题目提供的全部附件；独立运行时，以 `源码/` 为项目根目录，将原 `基础数据/` 放在该根目录下，保留目录结构。依赖包括NumPy、SciPy、LightGBM、openpyxl和Matplotlib。完整复现按第一问、第二问、第三问、第四问的顺序生成各自结果与缓存，再执行跨日补算及模板导出。仅补算时可使用已有完整缓存，无须重跑全年。

跨日补算顺序为 `boundary_prediction.py forecast`、`q4`、`q1`、`q3`，之后运行 `prepare_templates.py`、`refill_templates.mjs fill` 和 `verify_templates.py`。Excel写入依赖Codex内置Node环境的 `@oai/artifact-tool`；该依赖未打包。`publish_results.py` 与 `交付整理/` 用于本项目交付目录维护，不属于四问优化算法。

输入时标按区间结束时刻解释。模板首段00:10—00:20使用模型第二段，末段使用次日00:00—00:10的计划。第一问将给定光伏预测延拓一个日周期后重新求解；第三问和4-3在年末沿用最后一次预报的有效时段，对余下时刻用此前7天同一时刻的预报均值延拓。新增假设不改变原四问优化方法，也不将延拓预报当作真实发布的新预报。

结果表的合计按其显示窗口计算；各问子目录中的原模型汇总和明细仍按自然日统计。两种窗口的费用不可直接混用。每行末段来自次日零点的模型计划，不代表前一日零点已知的决策；4-2和4-3年末跨日费用使用预测电价。

附录的“核心源码”与本目录对应文件同步。更新后的AI说明补充时间对齐、跨日补算和材料整理的实际使用范围。Word已完成内容、源码与结构核对；按用户本次确认省略实际分页检查，分页仍未验证。
