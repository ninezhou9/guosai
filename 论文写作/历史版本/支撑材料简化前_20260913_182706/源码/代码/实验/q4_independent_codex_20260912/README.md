## 复现

在本目录执行；全新运行要求 `results/` 不存在或为空。保护已有结果时，先留档，或用
`run.py --output 新目录` 做独立计算。正式导出与审核读取本目录 `results/`。

```powershell
python -X utf8 test_model.py
python -X utf8 run.py --jobs 9
python -X utf8 deliver.py --sensitivity
python -X utf8 audit.py
```

已批准范围内中断续跑：`python -X utf8 run.py --jobs 9 --resume`。
恢复要求求解代码、原始输入、预测缓存、参数、策略及已完成日文件哈希一致。
若日文件已完成但检查点更新被打断，程序检测到孤立日文件会拒绝覆盖，需人工核对后处理。

运行器按策略组分进程，同组复用不依赖库存的外生模型；日期之间顺序推进。
每条策略保持自己的库存，模型与求解过程确定性运行，不使用随机预测情景。
数学测试的随机种子为20260912。
